# Segurança

## Relato responsável

Se encontrar uma vulnerabilidade, não publique credenciais, dados pessoais, arquivos privados ou uma prova de conceito explorável em uma issue pública.

Entre no [Discord oficial da ScR Community](https://discord.gg/NBtdqHuw72), abra um ticket e informe:

- a página ou endpoint afetado;
- o impacto observado;
- passos mínimos para reprodução;
- logs ou capturas sem senhas, tokens ou dados de terceiros.

A equipe fará a triagem e poderá solicitar detalhes adicionais pelo próprio ticket.

## Escopo

A versão mantida é a publicada na branch `main`. Dependências, configurações e segredos de produção não devem ser enviados em issues ou pull requests.
